# Titanic Passenger Data Analysis

## Project Overview
This project is an Excel-based data analysis capstone focused on Titanic passenger data.
The project transforms raw passenger records into meaningful insights using Microsoft Excel, PivotTables, PivotCharts, and an interactive dashboard.

## Project Objective
The main objective of this project is to analyze passenger characteristics and identify patterns related to survival.
The analysis focuses on:
- Gender
- Passenger class
- Age group
- Embarkation port
- Fare
- Family relationships
- Survival

## Dataset
The dataset contains:
- 418 passenger records
- 12 fields
- 3 passenger classes
- 3 embarkation ports
- 4 age groups

The fields include:
- Passenger ID
- Name
- Sex
- Age
- Age Group
- Survived
- Class
- Siblings/Spouse
- Parents/Children
- Ticket Number
- Fare
- Embarkation Port

## Tools & Techniques
Microsoft Excel was used for the analysis.

### Excel Techniques
- Data cleaning
- PivotTables
- PivotCharts
- Data analysis
- Dashboard creation
- Slicers
- Data visualization

## Dashboard
An interactive Excel dashboard was created to bring the analysis together in one view.
The dashboard includes filters for:
- Passenger Class
- Survival
It allows the user to interact with the data and explore different passenger groups.

## Key Findings
### Passenger Demographics
- 266 passengers were male and 152 were female.
- 3rd Class was the largest passenger group, with 218 passengers.
- Southampton was the dominant embarkation port, with 270 passengers.

### Survival
The analysis showed a strong difference in survival by gender:
- 152 of 152 female passengers survived.
- 0 of 266 male passengers survived.

### Fare
- The average fare across the dataset was €35.58.
- Fares ranged from €0 to €512.30.
- First Class had substantially higher average fares than Third Class.

### Family Travel
Passengers travelling with siblings/spouses and parents/children were concentrated mostly in Third Class.

## Conclusion
The analysis demonstrates how Microsoft Excel can be used to transform passenger data into meaningful insights.
The project highlights relationships between survival and factors such as gender, passenger class, age group, fare, embarkation port, and family travel.
